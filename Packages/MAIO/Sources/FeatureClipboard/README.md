# 剪贴板（`clipboard`）

记录复制过的文字、富文本、图片和文件路径。按 ⌃V 在文字光标处弹出列表，默认选中最近一条（最近复制或最近粘贴的），回车粘贴。交互参考 Windows 上的 Ditto。

## 命令

| 命令 | 参数 | 说明 |
|---|---|---|
| `clipboard.show` | 无 | 默认绑定 ⌃V；已打开时再按一次关闭。可在本功能设置页顶部直接录制；不想在某些 App 里生效：右键这个快捷键 →「编辑」，把生效范围设为"除这些 App 外" |

面板按键：

- 直接打字：搜索（所有词都要出现，不区分大小写）
- ↑ ↓：选择
- ⏎：粘贴
- ⇧⏎：粘贴纯文本
- ⌘1～⌘9、⌘0：粘贴第 1～10 条
- 空格：预览（搜索框有内容时空格是输入）
- ⌘P：固定 / 取消固定
- ⌘⌫：删除（搜索框为空时 ⌫ 也可以删除）
- Esc：关闭
- 鼠标：单击粘贴

## 右键菜单

每条历史右键：粘贴、粘贴为纯文本（富文本时）、复制到剪贴板（不粘贴）、贴图（图片或文字，通过截图功能的契约 `screenshot.pin`）、翻译（文字，契约 `translate.text`）、预览、固定、删除。

## 设置项（`config/features/clipboard.json`）

| 字段 | 默认值 | 说明 |
|---|---|---|
| `storageLimit` | `gb2` | 500 MB / 1 / 2 / 5 / 10 / 20 GB / `unlimited`（永久保留）。超过时删除最久没用过的，固定的不删 |
| `popupPosition` | `caret` | `caret` 文字光标处 / `mouse` / `center` |
| （去重） | — | 内容完全相同（所有格式都一样）的条目只保留一条、移到最前；最近 10 条里纯文本 / 文件路径 / 图片数据相同但格式不同的，删掉旧的、保存新的（固定的条目只移到最前）。依据存在 `clip.content_key`（文字先统一换行符、去掉首尾空白）。另外，同一个 App 10 秒内复制的两段文字互相包含（终端"选中即复制"拖动选区时），只保留最新的 |
| `searchMode` | `explicit` | `explicit`：按 ⌘F 或点搜索框才搜索，搜索时 ⏎ 结束搜索、再按 ⏎ 粘贴；`typeToSearch`：直接打字搜索、⏎ 粘贴。两种模式下输入法组字时的 ⏎ 都只上屏 |
| `caretFallback` | `center` | `caret` 时没有文字光标（不在输入框里、App 不提供光标位置）放哪：`center` / `mouse` |
| `pasteDirectly` | `true` | 选中后切回原 App 并模拟 ⌘V；关闭时只放进剪贴板 |
| `moveToTopOnPaste` | `true` | 粘贴过的条目排到第一 |
| `recordRichText` / `recordImages` / `recordFiles` | `true` | |

设置页可以查看占用（按类型、按月份），删除最旧的 N MB、删除某日期之前的、清空。固定的条目都不会被删除。

## 存储（ADR-0010）

- `data/clipboard/history.sqlite`：元数据和不超过 64 KB 的数据。
- `data/clipboard/blobs/<sha256>`：更大的数据（主要是图片）。
- 内容完全相同的复制只保留一条，再次复制会把它移到最前。

## 记录规则

- **不过滤密码**：密码管理器标记为"隐藏"的内容也照常记录（用户明确要求：纯本地使用，没有保密需求）。
- 跳过三种内容：MAIO 自己写入的（`app.maio.clipboard.marker`）、恢复剪贴板写回的（`org.nspasteboard.RestoredType`，例如翻译读取选中文字后的恢复）、系统自动生成的。
- 只保存这些类型：纯文本、RTF、HTML、PNG、TIFF、文件路径。单次超过 200 MB 的复制不记录。

## 权限

- 辅助功能：模拟 ⌘V 粘贴、读取文字光标的位置。
- 剪贴板读取：macOS 15.4 起读取剪贴板可能需要授权。2026-11 在本机检查时，状态已经是"始终允许"（2）；启动日志里会记录当前状态。

## 已知限制

- 有些 App 拿不到文字光标的位置（部分 Electron 应用），这时在鼠标处弹出。
- 文件只记录路径，原文件被删除或移动后无法粘贴。
- 列表一次加载最近 300 条，更早的需要搜索才能找到。
