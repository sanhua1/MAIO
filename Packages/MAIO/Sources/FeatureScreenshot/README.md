# 截图（`screenshot`）

替代 PixPin。按 ⌥F1 先冻结整个屏幕，再在静止的画面上框选，打开的菜单、悬浮提示也能截进去。
自动识别鼠标下的窗口（按住 ⌘ 识别控件），可以取色。截图自动复制（PNG），并写入截图历史。

需求、按键表、分阶段计划见 `docs/specs/M5-screenshot.md`；决策见 ADR-0011（截图流程）、ADR-0012（历史与贴图）、ADR-0024（录屏）。
**当前进度：** M5 的五个阶段都已实现；2026-11-08 追加录屏（MP4 / GIF，ADR-0024），等用户实测。

## 截图历史窗口

缩略图按日期分组；按日期（2026-11-03）、来源 App、识别过的文字搜索（只有做过识别的截图才有文字，不会自动识别每一张）。双击或 ⏎ 贴图，⌘C 复制，E 编辑标注，⌫ 删除，⌘W 关闭窗口；右键还可以识别文字、翻译、收藏（不会被自动清理）、在访达中显示。

## 长截图（P5，ADR-0014）

1. 框选区域后按 ⌘L（或工具栏的长截图按钮）。遮罩消失，选区外显示虚线边框；**选区右侧**是竖条面板：当前高度、「完成」按钮、整张长图的长条预览（实时更新），预览上的**绿框**表示当前画面在长图中的位置。右边放不下时放在左边。
2. **自己用滚轮或触控板往下滚**（MAIO 不发任何滚动事件）。选区开着一个视频流，每来一帧就在像素层和参照帧比较（容差 10，只比较有变化的像素），算出滚了多少，把新露出的部分按绝对位置接上。
   - 判断不了的帧（滚太快、和参照帧没有足够重叠、页面自己变了、内容重复分不清方向）**宁可不拼也不拼错**，面板提示"没对上"，滚回上次停下的位置再往下滚就能接上。
   - **往回滚不算错**：落在已拼范围里只更新位置（绿框跟着往上走），滚过起点会向长图头部扩展；之后继续往下滚能立刻接着拼。
3. 结束：点「完成」、按 Esc 或 ⏎、高度达到 30000 px。
4. 结果先写入历史，再打开标注编辑（长图会缩小以适应屏幕），之后 ⏎ 复制、⌘S 保存、⌘P 贴图都和普通截图一样。取消编辑也不会丢，可以在历史里找到。

注意：
- 截图时排除了 MAIO 自己的窗口，所以面板放在选区里也不会被截进去。
- 拼接按"当前画面在长图中的绝对位置"写入：吸顶栏只保留第一帧的，高度小于选区 1/4 的页脚只在最后出现。固定的侧栏会在每一段里重复出现（和其他截图软件一样）。
- 长截图进行期间，键盘按键都被 MAIO 接收（用来响应 Esc 和 ⏎），不会传给下面的 App；鼠标滚轮不受影响。
- 开始长截图前画的标注不会保留。

## 录屏（ADR-0024）

1. 框选区域后按 ⌘R（工具栏的 ⏺ 按钮，或用 ⌥F3 开始的截图直接 ⏎）。遮罩消失，选区外是虚线边框，下方是控制条。
2. 控制条上选 **MP4 / GIF**；MP4 可以打开**系统声音**、**麦克风**（两个都开时混成一条音轨）。⏎ 或「开始录制」开始，Esc 或「取消」退出。选择会记住，下次默认。
3. 录制中边框变红，控制条显示时长。**按键不会被拦截**，可以照常操作其他 App。
4. 结束：控制条上的「完成」，或再按一次 ⌥F3。「放弃」停止并删除文件。
5. 文件保存到录屏文件夹（默认 `~/Movies/MAIO`，文件名 `MAIO 2026-11-08 14.05.33.mp4`），同时把**文件**复制到剪贴板，可以直接粘贴到访达、微信、邮件。

实现要点（性能优先）：
- 画面、系统声音来自同一个 ScreenCaptureKit 流，排除 MAIO 自己的窗口和声音。画面没变时系统不发新帧。
- 麦克风用 AVCaptureSession 直接从默认输入设备采集：ScreenCaptureKit 自带的麦克风数据里会混进系统声音（实测）。
- MP4：流直接输出 YUV，原样交给硬件编码器（H.264 / HEVC，设置里选），不拷贝不转换。
  - 尺寸是 Retina 像素；H.264 超过 4096×2304 个像素时等比缩小。
- 声音：两路统一成 48 kHz 立体声，按时间戳对齐后相加（`Domain/Recording/AudioMixer`）。某一路没声音时最多等 0.2 秒。
- GIF：自己写的编码器（`Domain/Recording/GIF/`），边录边编、编好就写盘。
  - 默认按 pt 录（设置里可以改成 Retina）；
  - 每帧只编码变化的矩形，没变的像素透明；
  - 颜色 ≤256 种时用原色（无损），否则中位切分（不抖动）；
  - 编码跟不上时丢中间帧，播放速度不变；
  - 1440×900 整帧最坏约 28 ms，普通界面 7 ms。

## 识别文字与截图翻译（P4）

- 系统 Vision（`RecognizeTextRequest`）离线识别：精确模式、自动识别语言、语言校正，失败时用快速模式再试一次。
- Vision 逐行返回结果，`Domain/OCRLayout` 负责拼回文字：从上到下分行，同一行的多块（左右两栏、表格）用空格连接，行间距大于行高的 0.9 倍时空一行作为段落分隔。
- 识别时用的是带标注的最终图：马赛克、模糊盖住的文字不会被识别出来。
- 识别结果写入这条历史的 `ocrText`，历史窗口可以按它搜索。
- "删除换行"使用 `MAIOKit/Support/TextCleaner`（和翻译共用）。翻译通过契约 `TranslateTextContract` 交给翻译窗口。

## 数据

`data/screenshot/`：`index.json` + 每条记录一个目录（`original.png`、`thumb.png`；有标注后才有 `annotations.json`、`rendered.png`）。

## 权限

- 屏幕与系统录音：必需。授权后要退出并重新打开 MAIO（系统要求，进程内检测结果不会更新）。
- 辅助功能：识别控件时需要（MAIO 本来就有）。
- 麦克风：只在录屏打开"麦克风"时请求。系统声音包含在"屏幕与系统录音"里。

## 标注的实现要点

- 标注是矢量对象（`Domain/Annotation/`），撤销是整个列表的快照（最多 100 步）。
- 屏幕上的标注图层只覆盖选区，画的是"选区底图 + 标注"，和输出用同一套代码（`AnnotationRenderer`），所以看到的就是得到的。
- 马赛克、模糊只处理截图本身，总是先画；其他标注画在它们上面，不会被模糊掉。
- 马赛克每块取平均色，不保留原始像素。
- 大小连续可调（滑块 + 数字输入 + 滚轮），范围见 `AnnotationTool.sizeRange`。连续调整同一个对象合并成一步撤销（`AnnotationDocument.checkpoint(coalescing:)`）。
- 文字（`TextAppearance`）：工具栏永远显示并修改"当前这段文字"——正在输入的 > 选中的 > 下一次新建的；修改同时记成默认样式。
  - 标注的 color 是文字颜色；描边、底色用 `TextBox.backgroundColor`（旧数据没有时按文字颜色自动取黑或白）。
  - 外观不是"无"时，工具栏多出"■文字 / ■描边（底色）"两个按钮，选中哪个，色板就改哪个；外观为"无"时色板只改文字颜色。
  - 输入框本身的文字是透明的，看到的文字由标注图层按最终效果实时画出，输入时就能看到描边和底色。
  - 写完文字自动选中，可以马上改样式；文字工具下单击已有文字重新编辑。
- 有标注后，历史目录多出 `annotations.json`（坐标相对截图左上角，单位 pt，`index.json` 里记录 scale）和 `rendered.png`。

## 已知限制

- 剪贴板只写 PNG，不写 TIFF（TIFF 不压缩，5K 全屏约 60 MB，还会被剪贴板历史原样记录）。
- 屏幕锁定时系统截图接口不返回，2 秒后报错。
- 选区不能跨显示器。
- 多显示器还没有实机验证（开发机只有一台显示器）。
- 录屏不进截图历史；录制中不能暂停；GIF 不录声音。
