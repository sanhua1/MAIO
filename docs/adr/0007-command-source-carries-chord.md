# ADR-0007：快捷键触发的命令携带触发组合键

- 状态：已采纳
- 日期：2026-11-02
- 关联：ADR-0003（输入引擎）、M3 FeatureSwitcher

## 背景
窗口切换器的触发键由用户自定义（例如有人用 ⌘⇥，有人用 ⌥⇥）。切换器需要知道：
- 按住的是哪些修饰键：松开它们即确认选择；
- 主键是哪个：按住修饰键时再按它，切到下一项。

命令处理器原本只能拿到绑定 ID，拿不到组合键。

## 决定
`CommandSource.hotkey` 从 `hotkey(bindingID:)` 改为 `hotkey(bindingID:chord:)`。

## 备选方案
- 让功能读取绑定表：功能不能依赖 MAIOCore，否决。
- 在切换器设置里单独配置"按住的修饰键"：和快捷键页重复配置，容易不一致，否决。
- 会话开始时读取当前按住的修饰键：用户松开得快时读到的是空，无法区分"⌥⇥"和"⌘⌥⇥"，只作为辅助判断。

## 后果
- 枚举关联值变化，所有匹配 `.hotkey` 的地方需要更新（目前只有输入引擎和测试）。
