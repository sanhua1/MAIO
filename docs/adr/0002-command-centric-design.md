# ADR-0002：以命令为中心，功能间通过契约命令协作

- 状态：已采纳
- 日期：2026-11-02

## 背景
需要支持"任意快捷键 → 任意动作"，并且功能之间偶尔需要协作（如截图 OCR → 翻译），同时不能让功能互相耦合。

## 决定
- 功能对外只暴露命令（`CommandID` + 参数），触发器（快捷键 / 菜单 / URL）通过 Binding 连接到命令。
- 跨功能调用使用定义在 `MAIOKit/Contracts/` 中的类型安全契约 `CommandContract`。
- 请求用命令，事实用事件（`SystemEventService`）；不使用 NotificationCenter 做跨功能通信。

## 备选方案
- 功能直接互相依赖：耦合、容易循环依赖，否决。
- 全局事件总线（字符串事件 + 任意载荷）：类型不安全，行为难以追踪，否决。

## 后果
- 契约放在 MAIOKit 中，契约的增加需要克制。
- 提供方未启用时，调用方必须处理 `CommandError.unavailable`。
