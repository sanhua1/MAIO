# 系统默认的 🌐（Fn）快捷键

> 数据来源：macOS 26.5 上调用 SkyLight 私有函数 `CGSGetSymbolicHotKeyValue` / `CGSIsSymbolicHotKeyEnabled` 枚举编号 0–400（2026-11-02）。
> 重新生成：`swift scripts/diagnostics/list-globe-shortcuts.swift`
> 背景：MAIO 运行时可以接管这些组合（ADR-0004 更正）；希望退出 MAIO 后也不触发，可以在 MAIO 中禁用系统快捷键（带备份）。
> MAIO 内置版本：`MAIOCore/SystemShortcuts/SystemShortcutKnowledge.swift`；设置窗口 →「系统快捷键」页可以查看、禁用（自动备份）、一键恢复（见 ADR-0005）。

## 和 "fn + 字母/符号" 冲突的（最需要注意）

| 编号 | 组合 | 功能 | 备注 |
|---|---|---|---|
| 190 | 🌐Q | 快速备忘录 | 用户已关闭；关闭后 MAIO 的 fn+Q 正常工作（已验证） |
| 210 | 🌐A | 显示或隐藏程序坞（Apple 文档）；实际表现为焦点移到程序坞 | 已用 MAIO 实测禁用/恢复 |
| 214 | 🌐⇧A | 显示或隐藏 App（Apple 文档，macOS 26 起） | |
| 211 | 🌐C | 显示或隐藏控制中心（Apple 文档） | |
| 212 | 🌐N | 显示或隐藏通知中心（Apple 文档） | |
| 213 | 🌐M | 未确认（Apple 文档未列出） | |
| 196 | 🌐H | 显示桌面（Apple 文档） | |
| 197 | 🌐F | 未确认（Apple 文档未列出，可能是全屏幕） | |
| 209 | 🌐S | 未确认 | |
| 237 / 238 / 239 | 🌐⌃F / 🌐⌃C / 🌐⌃R | 窗口：填充 / 居中 / 恢复上一个大小（Apple 窗口平铺文档） | |

注意：🌐E（字符检视器）、🌐D（听写）、连按 🌐 在 Apple 文档中有列出，但**不在** symbolic hotkey 表里，由输入法 / "按下 🌐 键时"设置处理，能否被 MAIO 接管尚未测试。

## 方向键（窗口平铺，macOS 15+）

192–195（🌐←→↓↑）、198–200、205–206、240–255（🌐⌃ / 🌐⌃⇧ / 🌐⌃⌥⇧ + 方向键）：平铺左半/右半/上半/下半、四分之一、排列等。

## 不用担心的

编号 7–13、32–37、53–117、150–174、186–189 等（含键码 > 126 的媒体键：亮度、音量、调度中心、听写键等）：组合里出现的 🌐 是因为 **F1–F12、方向键、媒体键本身就自带 Fn 标志位**（例如 ⌃F2 = 将焦点移到菜单栏，⌃← = 切换桌面），不是"按住 🌐 再按某键"。只有在 MAIO 里绑定 "fn+F键" 或 "fn+方向键" 时才可能冲突。

## 关闭方法

系统设置 → 键盘 → 键盘快捷键… → 在对应分类中取消勾选。关闭后会写入 `~/Library/Preferences/com.apple.symbolichotkeys.plist`，
例如 🌐Q 关闭后的记录：`190 = { enabled = 0; value = { parameters = (113, 12, 8388608); type = standard; }; }`
（参数依次为：字符码、虚拟键码、修饰位；8388608 = 0x800000 = Fn）。
