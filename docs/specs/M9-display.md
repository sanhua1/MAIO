# M9 外接显示器（FeatureDisplay）

> 2026-11-21 用户提出，ADR-0028。

## 1. 痛点
- 日常合盖用，外接 4K 显示器（微星 MAG 272U E16，DP 接 M1 Pro），音箱插在显示器的 3.5 mm 口上。
- 声音输出是显示器时，系统调不了音量：按音量键（键盘或绑成音量键的鼠标侧键）只弹"无法调节"。
- 外接显示器的亮度系统也调不了，只能按显示器背后的按钮。

## 2. 需求（用户原话整理）
- **音量**：不管当前声音输出是哪个，按 Mac 的音量加减键就能调它。系统能调的输出（耳机口、USB 耳机）照常由系统调；
  系统调不了的（显示器音箱）由 MAIO 调。手感和原生一样。
- **亮度**：亮度键能调外接显示器；MAIO 菜单栏菜单里放外接显示器的亮度滑块。接了外接显示器才显示，没接就不显示。
  菜单里原来的功能开关列表去掉，「检查更新」「设置」「退出」保留。
- 控制中心（右上角）里的亮度滑块做不到：第三方只能往控制中心加按钮 / 开关，不能加滑块（已和用户确认）。

## 3. 做法
- DDC/CI：Apple Silicon 用私有的 `IOAVServiceWriteI2C / ReadI2C`（参考 MonitorControl）。实测这台显示器支持亮度（0x10）、
  音量（0x62），**不支持静音（0x8D）**，静音用"音量设 0、记住原值"模拟。
- 媒体键：输入引擎的媒体键过滤器（ADR-0028）。音量键在"当前输出系统调不了、而且对应一台能 DDC 调音量的显示器"时吞掉；
  亮度键在"鼠标所在屏幕是能 DDC 调亮度的外接显示器"时吞掉。其余放行给系统。
- 手感：每下 1/16（先对齐格点），⌥⇧ 微调 1/64，按住连续调，静音键切换，⌥ + 键打开对应系统设置；
  浮窗自己画（系统 OSDManager 在 macOS 27 上不显示），位置在右上角菜单栏下方。
- 显示器插拔 / 唤醒后延迟重新扫描；5 秒没碰过就先从显示器读回当前值（用户可能按过显示器自己的按钮）。

## 4. 不做 / 以后再说
- 软件调光（gamma / 叠加层）：这台显示器 DDC 正常，不需要。
- 控制中心控件（WidgetKit ControlWidget）：只能是按钮，收益小。
- 调音量的"啵"提示音。
- 对比度、输入源切换。
