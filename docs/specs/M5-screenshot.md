# M5 截图（FeatureScreenshot）需求与设计

> 状态：需求已和用户确认（2026-11-03）。**P1 代码已完成，等用户实测**。实现时按第 6 节分阶段进行，每个阶段结束都要交付给用户实测。
> 相关决策：ADR-0011（截图流程）、ADR-0012（截图历史与贴图）。
> 参考项目（只学思路，都是 GPL）：
> - `references/flameshot`：框选和标注交互、工具模型、撤销；
> - `references/ShareX`：长截图拼接；
> - `references/pinlume`：macOS 系统接口用法。代码质量差，不要学它的结构。

## 1. 用户的决定（原话要点）

- 目标：替代 PixPin。
- **不做**：二维码识别。**其余全部做**。
- **录屏（2026-11-08 追加）**：最初不做，后来用户要求加上：录 MP4 和 GIF，MP4 可以选录系统声音和麦克风；"性能优先"。用户的选择：入口两种都要（截图工具栏 ⌘R + 独立命令）、录完存文件夹并复制文件、两路声音混成一条音轨、编码在设置里可选（默认 H.264）。见 ADR-0024
- **截图和贴图都自动复制到剪贴板**。复制的 PNG 会被 M2 剪贴板自动记录，不需要额外对接。
- **截图历史**：可以找回以前的截图，并重新贴到屏幕上。
- **默认快捷键 ⌥F1**（截图）。
- **标注工具全部要做**：矩形、椭圆、箭头、直线、画笔、荧光笔、文字、马赛克、模糊、序号。
- **先写文档**。用户会手动压缩 session 后再开始实现。

## 2. 功能清单与验收标准

| # | 功能 | 验收标准 |
|---|---|---|
| F1 | 区域截图 | ⌥F1 后屏幕冻结，在约 150 ms 内显示遮罩，选区外变暗。拖动框选；八个手柄可以调整大小，拖动选区内部可以移动。显示 `宽×高`（按物理像素）；放大镜跟随鼠标 |
| F2 | 自动识别窗口和控件 | 鼠标悬停时自动高亮下面的**窗口**，单击直接选中。按住 ⌘ 或开启"识别控件"时，高亮**控件**（按钮、输入框、列表等）。多显示器都可用 |
| F3 | 全屏 / 窗口截图 | 截图时按 ⌘A 选中整个屏幕；另有命令 `screenshot.fullScreen` 和 `screenshot.window`（截取当前窗口，保留透明圆角） |
| F4 | 标注 | 十种工具（见 4.2）。颜色和粗细可调；画好的对象可以再次选中、移动、改色、删除；文字可以重新编辑；⌘Z / ⌘⇧Z 撤销和重做 |
| F5 | 贴图 | 截完后钉在屏幕最上层。可以拖动；滚轮以鼠标为中心缩放；可以调透明度、旋转；右键菜单；Esc 或双击关闭。**贴图时自动复制** |
| F6 | 完成后的操作 | ⏎ 或双击选区：复制并退出；⌘S：保存为文件（也会复制）；⌘P：贴图；全部操作都会写入历史 |
| F7 | OCR 文字识别 | 识别选区里的文字，用系统 Vision，离线，自动识别语言。结果窗口可以编辑、复制，也可以一键翻译 |
| F8 | 截图翻译 | 识别出文字后，通过 `TranslateTextContract` 交给翻译窗口 |
| F9 | 取色 | 放大镜下面显示鼠标处的颜色值；按 C 复制，⇧ 切换 HEX / RGB 格式 |
| F10 | 长截图 | 框选区域后点"长截图"：自动滚动并拼接，也可以自己手动滚动。可以随时停止；结果进入标注 / 复制 / 贴图流程 |
| F11 | 截图历史 | 历史面板（网格缩略图）：搜索（按日期和 OCR 出的文字）、重新贴图、复制、重新编辑标注、删除。有存储上限，可以清理 |
| F12 | 贴剪贴板内容 | 命令 `screenshot.pinClipboard`：把剪贴板里的图片（或文字渲染成的图片）直接贴到屏幕上，对应 PixPin 的 F3 |

## 3. 快捷键与按键

### 3.1 全局命令（在「快捷键」页可以修改）

| 命令 | 默认 | 说明 |
|---|---|---|
| `screenshot.capture` | **⌥F1** | 区域截图（包括窗口和控件识别） |
| `screenshot.pinClipboard` | **⌥F2**（用户决定，可以修改） | 贴剪贴板里的内容 |
| `screenshot.history` | 无 | 打开截图历史 |
| `screenshot.pinLast` | 无 | 重新贴最近一张截图 |
| `screenshot.fullScreen` / `screenshot.window` | 无 | 全屏截图 / 当前窗口截图，直接复制并写入历史 |
| ~~`screenshot.ocr` / `screenshot.translate` / `screenshot.scrolling`~~ | 无 | 2026-11-12 删除：都从框选后的工具栏进入 |

> ⚠️ ⌥F1 依赖系统设置"将 F1、F2 等键用作标准功能键"（`defaults read -g com.apple.keyboard.fnState` 为 1，用户当前是 1）。
> 如果关掉这个选项，F1 会变成亮度键，发出的是 NX_SYSDEFINED 事件而不是 keyDown，⌥F1 将无法触发。
> 设置页需要检测这个状态并提示用户。

## 4. 交互细节

### 4.1 截图遮罩

- **先截图再显示遮罩（冻结画面）**：按下快捷键后，先截取所有显示器，再显示遮罩，遮罩上画的是截到的静态图。这样打开的菜单、悬浮提示也能截进去（参考 pinlume）。
- 每个显示器一个遮罩窗口；只有鼠标所在屏幕上的遮罩接收键盘输入。
- 选区外是 45% 的黑色半透明遮罩。选区边框 1 px，强调色，带 8 个手柄。尺寸标签显示在选区左上角外侧，放不下时显示在内侧。
- **放大镜**：边长 120 pt，放大 8 倍，中心是十字线，下方显示坐标、颜色和 HEX 值。靠近屏幕边缘时换到鼠标另一侧。开始画标注后隐藏。
- **工具栏**：选区确定后出现，优先放在选区下方，放不下依次换到上方、内部（Flameshot 的规则）。
  - 左边是标注工具，中间是颜色和粗细，右边是撤销、重做、长截图、OCR、翻译、贴图、保存、复制（✓）。

### 4.2 标注工具

| 工具 | 键 | 选项 | 说明 |
|---|---|---|---|
| 矩形 | R | 颜色、粗细、实心 / 空心、圆角 | ⇧ 画正方形 |
| 椭圆 | O | 颜色、粗细、实心 / 空心 | ⇧ 画正圆 |
| 箭头 | A | 颜色、粗细 | 箭头大小随粗细变化；⇧ 吸附到 45° |
| 直线 | L | 颜色、粗细、虚线 | ⇧ 吸附到 45° |
| 画笔 | P | 颜色、粗细 | 路径做平滑处理 |
| 荧光笔 | H | 颜色（默认黄色）、粗细 | 正片叠底混合，下面的文字仍然可读；⇧ 画水平直线 |
| 文字 | T | 颜色、字号、粗体、描边或背景 | 单击放置，原地编辑，支持中文输入法；⌘⏎ 或点击别处结束编辑；双击已有文字重新编辑 |
| 马赛克 | M | 块大小 | 框选一块区域打码。**不可逆**：取块平均色，不保留原始像素（参考 Flameshot 的安全打码） |
| 模糊 | B | 强度 | 框选一块区域做高斯模糊 |
| 序号 | N | 颜色、大小 | 单击放置带数字的圆圈，编号自动加一；滚轮调整下一个编号 |

- 画好的标注都是**矢量对象**，以后可以选中、移动、调整、删除。
  - 没有选中工具时单击，可以选中对象；
  - 选中对象后改颜色或粗细，只作用于这个对象。
- **撤销 / 重做**：每次修改前，把整个对象列表保存一份快照（Flameshot 的做法），简单可靠。最多 100 步。
- 颜色有 8 个预设色和一个自定义色。上次用过的颜色和粗细会记住，保存在设置里。

### 4.3 输出

- 输出的图片 = 原始截图裁剪到选区，再把标注渲染上去。按物理像素输出：Retina 屏上 100 pt 宽的选区输出 200 px。
- 复制：**只写 PNG**（P1 实现时改的：TIFF 不压缩，5K 全屏约 60 MB，还会被剪贴板历史原样记录）。PNG 会被剪贴板历史记录下来。
- 保存：
  - 默认文件夹 `~/Pictures/MAIO`，可以在设置里改；
  - 文件名格式 `MAIO 2026-11-03 14.05.33.png`；
  - 设置"保存时询问位置"默认关闭。

### 4.4 贴图

- 贴图窗口：不抢焦点的面板，层级是 `statusBar + 1`（在 Dock 和菜单栏之上、弹出菜单之下）。在所有桌面空间显示，全屏 App 上方也能显示。
- 阴影自己画（留出外边距），可以关闭。鼠标悬停时边框高亮。
- 贴图从截图的位置原地出现（PixPin 的做法）。
- 每张贴图对应一条历史记录。在贴图里修改标注会更新这条记录，不会新建。
- 退出 MAIO 时不恢复贴图。以后如果需要，可以加"重启后恢复贴图"。

### 4.5 OCR 和翻译

- Vision 使用 `VNRecognizeTextRequest`，精度为 `.accurate`，开启自动识别语言和语言校正，失败时用 `.fast` 重试一次。
- 结果窗口是一个可以编辑的文本框，带"复制""翻译""删除换行"三个按钮。识别出的文字同时写入这条历史，用于搜索。
- 截图翻译：OCR 完成后直接调用 `TranslateTextContract`，打开翻译窗口，不显示 OCR 结果窗口。

### 4.6 长截图（ShareX + pinlume 的思路，自己实现）

1. 框选区域后按 ⌘L。遮罩消失，只留下选区边框，画在选区外 1 px，不会被截进图里。旁边显示"停止"按钮和当前高度。
2. 自动滚动：把合成的滚轮事件（像素单位，带 MAIO 标记）发到选区中心。用户也可以自己滚动。
3. 每隔一段时间截取选区，计算新的一帧相对上一帧滚动了多少。
   - 初步方案：用行哈希加容差匹配，忽略左右边缘（滚动条）各 `max(20 px, 宽 × 5%)`，自动检测顶部和底部固定不动的区域（吸顶栏、页脚）。
   - 备选方案：Vision 的 `VNTranslationalImageRegistrationRequest`。
   - 实现前先做实验，比较两者的准确度和速度。
4. 停止条件：用户点停止、按 Esc、连续 3 帧没有变化（到底了）、总高度达到 30000 px。
5. 拼接：先记录每一帧和它的偏移量，最后一次性合成，不要每一帧都重新分配整张图。
6. 合成结果进入正常流程（标注、复制、贴图、历史）。

### 4.7 截图历史

- 存储位置：`data/screenshot/`。
  - `index.json`：元数据。
  - 每条记录一个目录 `<id>/`，里面有：
    - `original.png`：裁剪后的原图，不含标注；
    - `annotations.json`：标注对象，可以重新编辑；
    - `rendered.png`：最终图片；
    - `thumb.png`：缩略图。
- 存储上限默认 2 GB，可以选永久保留；可以查看占用、按日期或大小清理。规则和剪贴板一样（ADR-0010 的 `RetentionPolicy` 思路，各自实现）。
- 历史面板：网格缩略图，按时间倒序，按日期分组。
  - 可以按 OCR 文字搜索；
  - 双击贴图；⌘C 复制；E 重新编辑；⌫ 删除。

## 5. 技术设计

### 5.1 模块结构（`Packages/MAIO/Sources/FeatureScreenshot/`）

```
ScreenshotFeature.swift / ScreenshotCommands.swift / ScreenshotSettings.swift
Domain/                     纯逻辑，可单测，不 import AppKit（可以用 CoreGraphics 的几何类型）
  SelectionGeometry.swift   选区：手柄判定、拖动、翻转、限制在屏幕内、按像素对齐
  Annotation.swift          标注对象（enum + 属性）、包围盒、点击判定、移动
  AnnotationDocument.swift  对象列表、选中、快照式撤销 / 重做
  ToolbarLayout.swift       工具栏位置计算
  Snapping.swift            ⇧ 吸附
  ScrollStitcher.swift      长截图偏移计算与拼接（输入是灰度行数据，便于用合成数据测试）
  ColorFormat.swift         HEX / RGB
  ScreenshotHistoryIndex.swift  历史元数据、清理规则
Infrastructure/
  ScreenCapturer.swift      ScreenCaptureKit 截全部显示器 / 区域 / 窗口
  WindowSnapshot.swift      冻结时的窗口列表（CGWindowList），排除 MAIO 自己的窗口
  ElementLocator.swift      辅助功能：控件识别
  AnnotationRenderer.swift  Core Graphics 渲染标注、马赛克、模糊（Core Image）
  TextRecognizer.swift      Vision OCR
  ScrollDriver.swift        长截图时发送滚动事件（通过 context.input.poster）
  ScreenshotHistoryStore.swift  文件存储
  ImageExporter.swift       写剪贴板、保存文件
UI/
  CaptureSession.swift      一次截图的流程控制（冻结 → 选择 → 标注 → 输出）
  OverlayPanel.swift / OverlayView.swift   每屏一个遮罩，用 AppKit 自己绘制（性能好）
  MagnifierView.swift / AnnotationToolbar.swift（SwiftUI）/ TextEditingOverlay.swift
  PinWindowController.swift / PinView.swift
  ScrollCaptureHUD.swift / OCRResultPanel.swift / HistoryBrowser.swift
  ScreenshotSettingsView.swift
```

- **遮罩和画布用 AppKit 的 NSView 自己绘制**：SwiftUI 每帧重建视图，拖动选区和画画笔时会掉帧。工具栏、设置页、历史面板用 SwiftUI。
- **跨功能协作**：
  - 剪贴板：不需要契约，PNG 写入剪贴板后会被监听器自动记录。
  - 翻译：使用已有的 `TranslateTextContract`。
- **对 MAIOKit 的改动**：预计不需要。滚动事件用已有的 `SyntheticEvent.scroll`。如果实验发现必须用"行"单位滚动或需要屏蔽鼠标悬停，到时再写 ADR。

### 5.2 权限

- 屏幕与系统录音：截图必需。`CGPreflightScreenCaptureAccess()` 的结果在进程整个生命周期内不会更新（pinlume 的注释），授权后要提示用户重启 MAIO。
- 辅助功能：控件识别、长截图自动滚动。已有。

### 5.3 性能目标

- 按下 ⌥F1 到遮罩出现：**≤ 150 ms**（用户对窗口切换的评价是"比 AltTab 快"，截图也要这个水准）。
  - 启动时预先创建好遮罩窗口；
  - 使用 macOS 26 新增的 `SCScreenshotManager.captureScreenshot(rect:)`，跳过很慢的 `SCShareableContent` 查询；
  - 截图和读取窗口列表同时进行。
- 拖动选区、画画笔时保持 60 fps 以上：只重绘变化的区域，遮罩用图层合成。

### 5.4 风险与需要先做的实验

| 风险 | 实验 / 对策 |
|---|---|
| 控件识别：遮罩挡在最上面，系统级的辅助功能命中测试会命中 MAIO 自己的窗口 | 先从冻结的窗口列表找到鼠标下的 App，再在这个 App 的元素上调用 `AXUIElementCopyElementAtPosition`。实验要验证这样能否绕开遮罩，以及速度是否够快（每次鼠标移动都要查询，需要节流和缓存） |
| `captureScreenshot(rect:)` 在多显示器、HDR 下的表现 | P1 开始时先写实验工具对比速度和画质；失败时退回 `SCScreenshotManager.captureImage` |
| 长截图拼接准确度（动画、懒加载图片、吸顶栏） | P5 开始前先对比两种算法，用 Safari、Chrome、备忘录、访达实测 |
| 遮罩里的文字工具要支持中文输入法 | 遮罩面板必须能成为 key window，并且激活 MAIO（参考翻译窗口的做法） |
| F1 被系统当作亮度键 | 设置页检测 fnState 并提示（见 3.1） |
| 内存：多屏 5K 冻结画面加长截图 | 结束截图后立即释放冻结的图；长截图的帧写入临时文件 |

## 6. 分阶段实施（每个阶段都要 `make check` 全绿并交给用户实测）
