# 手动验证清单

涉及系统权限、event tap、真实硬件的行为无法自动测试，每次相关改动后按此清单手动验证，并把结果写进 `docs/PROGRESS.md`。

## 准备
```sh
make run   # 构建并启动 Debug 版本（build/Build/Products/Debug/MAIO.app）
log stream --predicate 'subsystem == "app.maio"' --level debug   # 另开终端看日志
```
首次运行需要在"系统设置 → 隐私与安全性 → 辅助功能"中允许 MAIO。签名身份固定，重新编译后一般不需要重新授权；
如果授权后仍无效，在列表中删除 MAIO 再重新添加。

## 输入引擎
- [ ] 未授权时：菜单栏菜单显示"需要辅助功能权限"，设置窗口自动打开到"权限"页
- [ ] 授权后 2 秒内：通用页"键盘"状态变为"运行中"，无需重启
- [ ] `fn+a` 打开活动监视器（Fn 专项见 ADR-0004 的表格）
- [ ] 按住 `fn+a` 不放：只打开一次，且前台 App 不会收到一串 "a"
- [ ] 未绑定的按键（普通打字、⌘C/⌘V）完全不受影响，无延迟感
- [ ] 快捷键页"录制"：能录到 Fn 组合、⌘Tab 等系统快捷键；Esc 取消
- [ ] 录制期间按已绑定的快捷键，不会触发对应命令
- [ ] 绑定"仅在以下 App"：切换前台 App 后立即按规则生效

## 命令与配置
- [ ] `open "maio://run/system.openApp?app=com.apple.Calculator"` 打开计算器
- [ ] 绑定 `system.sendKeys`（例如 `fn+s` → `cmd+shift+4`）：触发系统截图
- [ ] 绑定 `system.runShell` 运行 `exit 1`：出现错误 HUD
- [ ] 手动把 `~/Library/Application Support/MAIO/config/bindings.json` 改坏后重启：出现错误提示，坏文件被备份为 `*.corrupt-*.json`，App 正常运行
- [ ] 删除出厂绑定 `fn+a` 后重启：不会被重新添加

## 鼠标滚动（FeatureScroll）
- [ ] 鼠标滚轮方向与 Mos 开启"反转"时一致；触控板方向不变、手感不变（双指滚动、惯性、回弹）
- [ ] 平滑：滚一格有顺滑动画，连续快速滚动会加速累积，反向滚动立即转向
- [ ] 设置中调节跨度 / 速度 / 时长立即生效；"恢复默认设置"可用
- [ ] ⌘ + 滚轮（浏览器缩放）正常；⇧ + 滚轮横向滚动（平滑）
- [ ] 添加 App 例外（例如某个游戏）：鼠标指向该 App 窗口时不平滑；指向其他窗口时照常平滑（以鼠标所指为准，不是前台 App）
- [ ] 绑定命令 `scroll.toggleReverse` / `scroll.toggleSmooth` 到快捷键，HUD 提示开关状态
- [ ] 设置 → 功能 → 关闭"鼠标滚动"：滚轮立即恢复系统默认行为；通用页"指针（滚轮）"显示"未使用"

## 窗口切换（FeatureSwitcher）
- [ ] 快速按一下 ⌥⇥：直接切到上一个窗口，不闪面板；再按一下切回来
- [ ] 按住 ⌥ 连按 ⇥：0.1 秒后出现面板，选中项高亮；松开 ⌥ 切换到选中窗口（同一 App 的不同窗口也能准确切换）
- [ ] ⇧⇥ / ← 反向；Esc 取消（焦点不变）；W 关窗、M 最小化、H 隐藏、Q 退出后列表即时更新
- [ ] 最小化窗口、隐藏 App 出现在列表末尾，切换后被恢复
- [ ] 鼠标悬停选中、点击切换
- [ ] 有"屏幕与系统录音"权限时显示缩略图；没有时显示图标，设置页有授权提示
- [ ] 在快捷键页把触发键改成 ⌘⇥：系统自带的 App 切换器不再出现，由 MAIO 接管；松开 ⌘ 时切换
- [ ] 切换过程中键盘不会卡死：任何情况下松开修饰键后键盘恢复正常

## 系统快捷键（ADR-0005）
- [ ] 设置 →「系统快捷键」：列出系统 🌐 快捷键（约 18 个）及 Apple 文档链接；未公开说明的显示编号

- [ ] 点「恢复」或调用 `open "maio://run/maio.restoreSystemShortcuts"` → 系统行为恢复，备份清空
- [ ] 重启 MAIO 后备份仍在；系统设置 → 键盘快捷键中的状态与 MAIO 一致（可能需要重新打开系统设置）
- [ ] 系统集成测试：`MAIO_SYSTEM_TESTS=1 swift test --package-path Packages/MAIO --filter SystemShortcutIntegration`

## 自动更新（ADR-0016）
- [ ] 菜单栏「检查更新…」：已是最新时提示"已是最新版本"
- [ ] 发布新版本后：自动检查（或手动检查）→ 后台下载 → 弹窗显示版本和更新说明
- [ ] 点「安装并重启」→ MAIO 退出、几秒内新版本自动打开，提示"已更新到 x.y.z"；快捷键、滚动、截图不用重新授权
- [ ] 「跳过这个版本」后自动检查不再提示，手动检查仍然提示
- [ ] 设置 › 通用 › 更新：关掉自动检查后不再检查

## 生命周期
- [ ] 设置 → 功能 → 关闭"系统动作"：相关快捷键在快捷键页显示"不可用"，按下不再被拦截

- [ ] 通用 → 登录时启动（建议先 `make install`，用 /Applications 中的版本）
